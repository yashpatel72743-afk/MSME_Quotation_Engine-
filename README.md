# MSME_Quotation_Engine-


The MSME Quotation Engine takes product details and customer requirements,
validates the input, applies quantity, tax, and discount rules, and generates a final quotation.

# This project designed using professional Python project structure 

• Data validation
• Business logic
• Exception handling
• Logging
• Pydantic models
• API integreation using FastAPI
• Testing support

# Features

• Product catalogue management
• Product validation
• Quantity validation
• Tax calculation
• Discount calculation
• Final quotation calculation
• Input validation
• Error handling
• API ready architecture
